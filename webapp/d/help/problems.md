## Problem manager

The [problem manager](/problems) documents current problems. Each problem gets its own tag, such as `problem:homecontent`, and solutions with that tag belong to it.

Use the **Summary** tab for an overall summary of the problem. Expect to update it the most as work on the problem goes on.

| Tab | Question |
| --- | --- |
| Who | Who is having this problem? |
| What | What is the problem? |
| Where | Where is this problem occurring? |
| When | When does this problem occur? |
| Why | Why is this a problem? |
| How | How can this problem be replicated? |

Describe the problem from the user's point of view, and never prescribe a solution. See [declare and define the problem](/help/workflow).

Only the problem's owner can save it. To take it over, remove the owner's `person:` tag and save.

When all its solutions are implemented or dropped, click **Publish** to turn the problem into a [story](/help/stories).
