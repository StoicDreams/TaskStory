## Solution manager

The [solution manager](/solutions) documents possible solutions to a problem. Give each solution its problem's tag, such as `problem:homecontent`, so it belongs to that problem. The easiest way is to set the tag filter to the problem before adding solutions.

| Tab | Use it for |
| --- | --- |
| Summary | Your findings and progress as you work through the solution. |
| Investigation | Notes and findings from investigating this solution. |
| Testing | Results of any prototyping, testing, and benchmarking. |
| Notes | Developer notes. |

Only the solution's owner can save it. When the problem is published, you mark each solution as implemented or dropped, and both are kept in the [story](/help/stories).
