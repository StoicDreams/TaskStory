## Writing in Markdown

Every text field in Task Story supports Markdown. Switch to **Both** to see the result as you type.

| To get | Type |
| --- | --- |
| A heading | `## Heading` |
| Bold | `**bold**` |
| Italic | `*italic*` |
| A link | `[text](https://example.com)` |
| A bullet list | `- item` on each line |
| A numbered list | `1. item` on each line |
| Inline code | `` `code` `` |
| A quote | `> quoted text` |

Put a code block between two lines of three backticks. Write a table with `|` between columns and a line of `---` under the header row.

HTML and Web UI components are removed when Markdown is shown, so what you write can't run code on a teammate's screen.
