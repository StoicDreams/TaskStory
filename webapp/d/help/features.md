## Feature manager

The [feature manager](/features) documents what a product does. Each feature gets its own tag, such as `feature:signin`.

Define a few key features when a project starts if you know them, and keep them short. Add features as solutions implement them, and update them when later solutions change them.

| Tab | Question |
| --- | --- |
| Who | Who will benefit from this feature? |
| What | What is this feature? |
| Where | Where is this feature used? |
| When | When is this feature used? When is it needed? |
| Why | Why is there a need for this feature? Why will people use this feature? |
| How | How will users discover the feature? How will it be used? |
