## About Task Story

Task Story is a project tracker for software teams that ship in short, continuous iterations. It is built around Continuous Agile Software Engineering (CASE): write up the problem before choosing a fix, try more than one solution, and publish a story of what shipped and what you dropped.

Task Story is made by Stoic Dreams, and runs on the Stoic Dreams Web UI framework described below.
